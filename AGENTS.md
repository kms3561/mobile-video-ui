# Project Rules

- Keep the original static prototype files intact unless the user explicitly asks to change them.
- Place the Expo React Native app inside `mobile-app/`.
- Build mobile-first for both iOS and Android with Expo-compatible packages.
- Use placeholder data only until backend, auth, database, and storage work is explicitly requested.
- Keep UI changes consistent with the minimalist dark visual design.
- Run type-checking and linting when available before reporting completion.
